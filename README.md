This game was a solo project for the game jam "DattelJam" which is the 4th Game Jam hosted by Karlsruhe Institute of Technology. The game jam had a duration of around 2 days with the theme "You are your own enemy".

This is a round based bullet hell game, where the player movements are recorded and saved as enemies in later rounds.
Thus, as the rounds progress, the player must combat enemies mimicking the movements of the player from all previous rounds.

Controls:
WASD/Arrow keys to move.
The ships shoot automatically on a timer.
